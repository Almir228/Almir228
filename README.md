## Образование и опыт

- Бакалавриат Московского физико-технического института.
- Математическая подготовка: теория вероятностей, статистика и численные методы.
- Учебные проекты на Python и C++: анализ таблиц, измерение производительности алгоритмов и математическое моделирование.
- Дипломная работа по математической физике и калибровочным теориям; интерес к исследованиям и строгой аргументации.
